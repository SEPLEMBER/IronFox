Subject: [PATCH] perf: reduce thumbnail cache size and quality to improve performance on low-end devices

Reduces the disk cache limit for thumbnails from 100MB to 1MB and
lowers the JPEG encoding quality from 90 to 1. This significantly
reduces CPU usage during bitmap compression and disk I/O, preventing
UI lags on older devices while preserving basic visual history.
